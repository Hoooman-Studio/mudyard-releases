# Mudyard desktop app

Download the latest version from the [Releases page](https://github.com/Hoooman-Studio/mudyard-releases/releases/latest): the `arm64` `.dmg` for Apple silicon (M1 or later), `x64` for Intel. Open it and drag Mudyard into Applications.

The app updates itself: updates download in the background and install when you quit the app.

This repository only hosts the downloads. The source is in the private `mudyard-next` repository, whose CI publishes here on each push to its `desktop` branch.
